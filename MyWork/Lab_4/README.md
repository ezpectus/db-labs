# Lab 4 — OLAP: JOIN, агрегація, GROUP BY, HAVING

## 🇺🇦 Українською

Аналітичні запити в стилі **OLAP**: статистика та звіти по даних VideoHub. Агрегатні функції (`COUNT`, `SUM`, `AVG`, `MIN`, `MAX`, `ROUND`), групування `GROUP BY`, фільтрація груп `HAVING`, усі типи `JOIN` (`INNER`, `LEFT`, `FULL OUTER`, `CROSS`), багатотаблична агрегація з `COUNT(DISTINCT ...)` проти fan-out та підзапит «автори вище середнього по сайту».

### Файли

- `queries.sql` — 6 блоків аналітичних запитів
- `tasks.md` — завдання лабораторної
- `report_lab4.md` / `report_lab4.pdf` — звіт
- `screenshots/` — скріншоти результатів у pgAdmin

---

## 🇬🇧 English

**OLAP-style** analytical queries: statistics and reports over VideoHub data. Aggregate functions (`COUNT`, `SUM`, `AVG`, `MIN`, `MAX`, `ROUND`), `GROUP BY` grouping, `HAVING` group filtering, all join types (`INNER`, `LEFT`, `FULL OUTER`, `CROSS`), multi-table aggregation with `COUNT(DISTINCT ...)` to handle fan-out, and a subquery finding "authors above the site-wide average".

### Files

- `queries.sql` — 6 blocks of analytical queries
- `tasks.md` — lab assignment
- `report_lab4.md` / `report_lab4.pdf` — report
- `screenshots/` — result screenshots from pgAdmin
