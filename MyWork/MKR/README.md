## Завдання

> Спроектувати базу даних для платформи продажу квитків на події, яка управляє майданчиками, подіями, типами квитків, клієнтами та покупками квитків.

## Файли

| Файл | Завдання |
|---|---|
| `1_schema.sql` | Схема БД (6 таблиць) + тестові дані |
| `2_oltp.sql` | 8 OLTP запитів: по 2 INSERT, UPDATE, DELETE, SELECT |
| `3_olap.sql` | 4 OLAP запити (аналітика) |

Файли виконуються по черзі: `psql -f 1_schema.sql`, потім `2_oltp.sql`, потім `3_olap.sql`.

Ціна і кількість доступних квитків залежать від події, тому для них окрема таблиця `event_tickets` (зв'язок подія–тип квитка).
