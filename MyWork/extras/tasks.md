# Extras — Додаткові SQL-запити (Window Functions, CTE, Recursive)

## Контекст

Інша БД — університетська: студенти, групи, викладачі, курси, записи на курси, пререквізити.

### Схема БД

| Таблиця | Опис |
|---------|------|
| `contact_data` | email, phone |
| `teacher` | name, surname, contact_data_id, qualification (ENUM: бакалавр/магістр/доктор філософії/доктор наук) |
| `student_group` | name (формат __-_), start_year, curator_id → teacher |
| `student` | name, surname, profession, contact_data_id, group_id |
| `course` | name, credits, student_year (1-4), is_active, teacher_id |
| `enrolment` | course_id, student_id, grade (може бути NULL) |
| `course_prerequisite` | course_id, prerequisite_course_id (не може = course_id) |

## Завдання

### Завдання 1: Успішність студентів за роком навчання

Порахувати середню оцінку студента по всіх предметах (NULL = 0), потім середню оцінку всіх студентів за навчальним роком. Вивести: ім'я, прізвище, навчальний рік, середню оцінку студента, середню оцінку по року.

**Ключові конструкції:** `AVG`, `COALESCE`, `OVER (PARTITION BY)`, `GROUP BY`

### Завдання 2: Середній бал студента vs середній бал по групі

Для кожного студента знайти його середній бал у порівнянні з середнім балом по групі. Вивести: ім'я, прізвище, назву групи, середній бал студента, середній бал групи.

**Ключові конструкції:** `DISTINCT`, `AVG OVER (PARTITION BY)`, `INNER JOIN`

### Завдання 3: Статистика записів на курси для кожного року навчання

Для кожного року навчання: кількість курсів, кількість записів, кількість студентів з оцінками (не NULL).

**Ключові конструкції:** `COUNT(DISTINCT)`, `FILTER (WHERE)`, `LEFT JOIN`, `GROUP BY`

### Завдання 4: Мінімальний семестр для кожного курсу

Для кожного курсу знайти в якому мінімальному семестрі він може читатись, враховуючи ланцюжки пререквізитів (рекурсія).

**Ключові конструкції:** `WITH RECURSIVE`, `UNION ALL`, `MAX`

### Завдання 5: Студенти з більшою кількістю курсів за середню

Знайти всіх студентів, які записані на більше курсів, ніж в середньому студенти.

**Ключові конструкції:** `CTE`, `COUNT`, `AVG`, `CROSS JOIN`, `WHERE`

### Завдання 6: Топ-3 студенти у кожному курсі

Знайти топ-3 студентів у кожному курсі за отриманими балами (NULL-оцінки не враховуються).

**Ключові конструкції:** `ROW_NUMBER() OVER (PARTITION BY ... ORDER BY ... DESC)`, `CTE`, `WHERE`
